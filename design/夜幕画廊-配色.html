八套内置配色

选定夜幕画廊后，配色做成主题随软件一起发布：6 套深色、2 套浅色，在「设置 → 外观」里切换，也能跟随系统在一深一浅之间自动切换。每套主题就是一组颜色变量；画师、作品、角色、一般、元五类 tag 的颜色沿用 Danbooru 的习惯，换哪套主题都能一眼认出。

整窗预览

点选一套配色，下面的窗口和「设置 → 外观」样稿会一起切换。

八套一览

同一画面在八套配色下的样子。色块依次是底色、面板、正文和强调色。

软件里怎么切换

「设置 → 外观」。这张按 Windows 窗口画，右上角是最小化、最大化和关闭；Mac 版把红黄绿按钮放进左侧栏顶部，其余布局一样。

主题怎么落地

颜色只写在 src/theme/themes.json 一处，由它生成 src/styles/themes.css；设置页的主题列表也读这份 JSON。

规则

  • 组件只引用变量，不写死颜色。叠在图片上的角标和悬停信息固定用深色半透明，不随主题变。
  • tag 分类色跟 Danbooru 一致：画师红、作品紫、角色绿、一般蓝、元橙。深色和浅色主题各用一组，不跟着主题色走。
  • 状态色和强调色分开：琥珀的强调色偏黄，所以它的「限速退避」改用珊瑚橙，避免和强调色混淆。
  • 默认深色用樱夜、浅色用晨雾；打开「跟随系统」后随系统明暗自动切换。
  • 以后新增主题：在 JSON 里加一项，运行 pnpm themes 重新生成 CSS 即可。

每套主题包含的变量

--bg窗口底色
--panel侧栏、详情面板
--raised / --raised-2搜索框、按钮等控件的两级底色
--line / --line-2分隔线与描边
--chiptag 标签底色
--fg-1 / --fg-2 / --fg-3标题正文、次要文字、说明文字
--accent / --accent-fg / --accent-soft强调色、强调色上的文字、选中与焦点的浅底
--glass底部浮条等半透明浮层
--ok / --warn / --err完成、限速退避、失败
--shadow浮层阴影
--tag-artist 等 5 个tag 分类色，按深浅两组共用
